# i18n Vollständige Lokalisierung — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Alle hardcoded englischen Strings in der Sublarr-UI durch `t()` ersetzen, fehlende DE-Übersetzungen fixen, und `fallbackLng` auf `'de'` setzen.

**Architecture:** Datei-für-Datei-Ansatz. Für jede betroffene TSX-Datei: Keys in beide Locale-Dateien eintragen, dann `t()` im JSX einsetzen. Kein neuer Namespace — alle neuen Keys landen im bestehenden Namespace der jeweiligen Komponente.

**Tech Stack:** React 19, i18next, react-i18next, TypeScript — keine neuen Dependencies.
