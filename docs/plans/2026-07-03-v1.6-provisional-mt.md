# Provisional Machine-Translation — Flag + Provisional State (backend, phase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a Sublarr-produced machine translation a *provisional* result instead of a final one: record the translated output as a managed `subtitle_downloads` row flagged `source="machine_translation"`, and — when the user opts in per profile — keep the wanted item alive in a `provisional` state instead of deleting it, so a later pass can seek the human original.

**Architecture:** Today every translate-completion site records only the *source* provider sub, never the translated output, and calls `delete_wanted_item` on success — so MT output is invisible to the DB and no further search happens. This plan adds a single `record_mt_output` helper that records the translated output (`source="machine_translation"`, score 0) and then either sets the wanted to `provisional` (keep-seeking on) or deletes it (current behaviour). A `provisional` item is **inert to the normal scanner** (which only searches `status="wanted"`), so there is no re-translate loop. Three new per-profile config fields drive the decision. The actual re-seek/replace of the original is a documented follow-on (`#8b`).

**Tech Stack:** Python 3.11, Flask, SQLAlchemy, Alembic, pytest.

## Scope note

**Phase 1 (this plan): flag MT + provisional state + config.** The re-seek of the
original (make `upgrade_scan` re-queue `provisional` items with translation
disabled, replace the MT when a real provider original scores ≥ the configured
minimum, pinning, notify/approve UX, frontend badge) is **phase 2 (`#8b`)** —
it needs the search-flow "original-only, no re-translate" wiring and is tracked
separately. Phase 1 is self-contained and safe (provisional items are inert to
the normal `status="wanted"` scanner, so nothing re-translates them).

```python
"""Provisional machine-translation: record MT output + keep the wanted item
provisional (seeking the human original) instead of deleting it, per profile.

Phase 1 (this module): flag + provisional state. The re-seek/replace of the
original is phase 2 (upgrade_scan MT-awareness).
"""

from __future__ import annotations

import logging
import os

logger = logging.getLogger(__name__)


def resolve_keep_seeking(item: dict) -> bool:
    """Return whether this wanted item's profile wants MT kept provisional.

    Fails safe to False (current delete-on-translate behaviour) on any error.
    """
    try:
        from db.repositories.profiles import ProfilesRepository  # adapt to real API

        # Resolve the profile from the item's series/movie id, read the field.
        # Use whatever resolver the profiles repo actually exposes
        # (get_series_profile / get_movie_profile / get_default_profile).
        prof = _resolve_profile_for_item(item)
        return bool(prof and getattr(prof, "mt_keep_seeking_original", 0))
    except Exception as e:  # pragma: no cover - defensive
        logger.debug("resolve_keep_seeking failed, defaulting to delete: %s", e)
        return False


def finalize_translation(
    item_id: int,
    item: dict,
    output_path: str,
    target_lang: str,
    target_fmt: str,
) -> None:
    """Record the MT output + set the wanted provisional (or delete), per profile.

    Flagging the MT row as source="machine_translation" is ALWAYS done; only the
    keep-provisional-vs-delete decision is gated by the profile.
    """
    from db.providers import record_subtitle_download
    from wanted_search import delete_wanted_item, update_wanted_status

    try:
        record_subtitle_download(
            provider_name="translation",
            subtitle_id=f"mt:{os.path.basename(output_path)}",
            language=target_lang,
            fmt=target_fmt,
            file_path=output_path,
            score=0,
            source="machine_translation",
        )
    except Exception as e:
        logger.warning("finalize_translation: failed to record MT row for %s: %s", output_path, e)

    if resolve_keep_seeking(item):
        update_wanted_status(item_id, "provisional")
    else:
        delete_wanted_item(item_id)
```
